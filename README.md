# indiana-plans

This project analyzes Marketplace health plan data for Indiana. I filtered the Marketplace dataset to Indiana plans and created a scatter plot showing the relationship between monthly premiums and individual medical deductibles.

The final dataset contains 4,429 Indiana plans.

The scatter plot displays:
- Monthly premium on the x-axis
- Deductible on the y-axis

The project includes the Python code used for the analysis and the resulting scatter plot.
